3) КАК ИГРАТЬ
-------------
1. Мастер открывает /master/ → на старте под логотипом «Сессия» (или то же в меню ☰) → Новый стол
2. Ссылка игрокам копируется, ключ мастера скачивается файлом pipboy-КОД.txt
   Код стола можно скопировать иконкой рядом с «СТОЛ *****»
3. Игрок на /play/ может:
   — создать персонажа в «Непривязанные персонажи» (стол мастера не нужен)
   — или войти по коду/ссылке и создать персонажа уже за столом
   Кнопка «Стол» рядом с крестиком на непривязанном листе — копия на стол
   (список ваших столов или новый код). У мастера персонаж появляется сразу.
4. С другого устройства мастер вставляет ключ из файла (одна строка КОД-ТОКЕН)
5. Мастер удаляет стол кнопкой «Удалить стол» — персонажи на сервере тоже исчезают
6. Игрок в хабе может удалить своего персонажа (X на карточке) или убрать стол из списка — свои персонажи на сервере тоже удаляются. Сам стол удаляет только мастер

Кнопка «экран» у мастера и игрока растягивает Pip-Boy на всё ОКНО браузера (не F11). Модалки при этом работают. Повторный клик возвращает рамку 1024×768.

В Telegram Mini App хаб (столы, персонажи, PIN) пишется в CloudStorage аккаунта —
с телефона и с компьютера в том же Telegram они общие.
В обычном браузере — localStorage этого устройства.

Порт только 8787. VPN на этом же VPS не трогаем (Amnezia, UDP 30463).
ОС сервера не переустанавливаем.

------------------------

   (версия для мастера и/или версия для игроков)

3. На VPS подтягиваем код (сессии игроков при этом НЕ стираются):

   curl -fsSL https://raw.githubusercontent.com/Alexander12039409/fallout-2d20-pipboy/main/deploy/install.sh | bash

   Или уже зайдя по SSH:
     git -C /opt/pipboy fetch origin
     git -C /opt/pipboy reset --hard origin/main
     cp -f /opt/pipboy/deploy/Caddyfile /opt/pipboy-caddy/Caddyfile
     systemctl restart pipboy
     systemctl reset-failed pipboy-https || true
     systemctl restart pipboy-https

Локальная проверка на ПК (нужен Node.js):
  запустить-локально.bat
  или:  node "E:\fall app\pipboy-sync\server.js"

9) ЧТО ВОШЛО В V4 (lib)
-----------------------
- Каталог из основной книги: 94 перка, оружие (в т.ч. рукопашное и взрывчатка), моды ближнего боя, одежда/шлемы/силовая, препараты, еда, напитки, аптечка, патроны
- Счётчик «КОЛ-ПАТРОН» +/− без обоймы и релоада (как в правилах: патроны есть / нет)
- Справка в приложении: торговля, вес, моды, еда/химия, силовая броня
- Telegram /help обновлён под V4
- Старые столы подхватывают новые позиции базы, не затирая кастом мастера
- Каталог v5: моды только на свои пушки и броню (нож без магазина, одежда — подкладка, силовая без боевых апгрейдов); вкладки инвентаря по группам; иконки расходников/модов не сведены к аптечке
- Каталог v6 (2026-08-31): полная еда/напитки/журналы из книги; броня охранника Волт-Тек, силовая рейдеров, обшивка роботов; поиск без дефисов и «ё» (10мм = 10-мм, винтовка находит карабин); сломанная строка каталога больше не прячет весь список; сессия игрока не затирает встроенную базу; лист за столом берёт инвентарь стола, а не пустую копию из хранилища. Непривязанный персонаж игрока сохраняет инвентарь в хаб — раньше предмет мелькал на карточке и пропадал после обновления. После Ctrl+F5 старый pipboy_master_db подхватывает v6, кастом мастера не удаляется.
- Название оружия на карточке собирается по книге (стр. 87–88): префиксы модов перед базовым именем (глушитель → «Тихий 10-мм пистолет»), ложа на пистолете меняет форму (лазерный пистолет → лазерная винтовка, лазер Института / гладкоствол → карабин). В каталоге и в сохранении персонажа по-прежнему baseId без префиксов; инвентарь, броня и моды не перезаписываются. BUILTIN_DB_VERSION остаётся 6.
- Силовая броня: каркас не снимается при надевании пластин. Над SPECIAL появляется «Надет каркас силовой брони», СИЛ на листе = 11 (закрыта), своя СИЛ в сохранении не меняется. Пластины без каркаса нельзя надеть. Снятие/удаление каркаса снимает пластины.
- Уведомления — пуши сверху экрана Pip-Boy (заголовок + текст, 3 сек / крестик / свайп). Новое уведомление сразу скрывает предыдущее. Браузерный alert в Telegram больше не используется.
- Генератор групп противников (только мастер, вкладка ЗАМЕТКИ при живом столе): кнопка «Создать группу противников» → пустая карточка с «добавить противника». Пошагово: уровень → человек/чудовище и ранг главы 10 → кто именно. Статы из профилей книги, уровень масштабирует карточку. Людей снаряжает из каталога: чем выше уровень, тем выше редкость оружия, моды, броня и расходники. На столе — компактные карточки по 3 в ряд (SPECIAL/характеристики, защита, атаки, ОЗ тек/макс). Клик открывает упрощённый лист справа, как у персонажа: снаряжение списком (у оружия — характеристики в скобках, у брони — зона: «Левая рука», «Правая рука»), предметы можно добавить из базы. Игроки группы не видят. Файл: npc-gen.js.
- 3D-кубики (2026-09-01): исходник E:\dice roller, в приложение собран бандл Fallout App Pip Boy Public Version/dice/. Мастер: в меню ☰ после дивайдера блок «Бросить кубик» (число, тип D6/D20/D20 hit, кнопка). Игрок: иконка кубика слева от «Основное»; на десктопе выпадающая панель, на мобилке нижняя шторка.

# Pip-Boy Master OS (v3)

Это приложение мастера. Игроки открывают соседнюю папку `adaptive-v3-player` **через сервер**, а не файлом с диска.

Полная инструкция: [`../pipboy-sync/README.md`](../pipboy-sync/README.md)

Запуск: `../pipboy-sync/start.bat` → http://localhost:8787/master/

Без сервера мастер по-прежнему работает локально (как v2): можно открыть эту папку любым статическим сервером. Кнопка «Сессия» заработает только когда запущен `pipboy-sync`.

# Fallout 2d20 — Pip-Boy

Мастер и игроки в интернете. Без локального сервера, без IP и портов.

## Как играть

1. Мастер открывает `/master/`
2. Иконка людей → **Создать**
3. Ссылка игрокам копируется сама. Она **не меняется**.
4. Игрок открывает ссылку → сначала только логотип Fallout → сессия найдена → персонажи и карта.

Сессия живёт на сервере. Мастеру не обязательно быть онлайн. По той же ссылке можно зайти завтра.

Свою ссылку мастера (с `k=`) сохраните: с другого устройства карта снова будет редактироваться.

## Запуск у себя

Нужен Node.js 18+.

```
node pipboy-sync/server.js
```

Откроется http://localhost:8787/master/

## Выкладка в интернет

Репозиторий уже собран как одно приложение (мастер + игрок + сервер).

Самый прямой путь — [Railway](https://railway.app) или [Koyeb](https://www.koyeb.com): New project → Deploy from GitHub → этот репозиторий. Команда старта: `node pipboy-sync/server.js` (или Docker из `Dockerfile`).

Диск для сессий: переменная `DATA_DIR` (в Docker по умолчанию `/data/sessions`). Без диска сессии живут, пока жив контейнер; с диском — переживают перезапуск.

## Что в папках

| Папка | Назначение |
| --- | --- |
| `Fallout App Pip Boy Public Version/версия для мастера` | Приложение мастера (рабочая копия) |
| `Fallout App Pip Boy Public Version/версия для игроков` | Приложение игрока (рабочая копия) |
| `Fallout App Pip Boy Public Version v3` | Снимок V3 на диске (git tag `v3`) |
| `pipboy-sync` | Сервер: сессии, живое обновление, раздача обоих UI |
| `adaptive-v3`, `adaptive-v2`, `adaptive` | Старые копии, не править |

База оружия, иконки и правила лежат в git — на сервер уезжает готовое приложение.
